Data tetap di browser ini

Tidak membutuhkan Google Cloud, API key, npm, atau hosting. Google Maps dan WhatsApp tetap membutuhkan internet.

Impor menambahkan prospek unik tanpa menimpa prospek lama atau identitas pengirim. Daftar jangan hubungi selalu digabungkan. Riwayat dari backup tidak dimasukkan ulang.

Pulihkan backup utuh mengganti prospek, riwayat, dan pengaturan dengan isi backup. Download backup data sekarang sebelum pemulihan. Nomor jangan hubungi yang sudah ada tetap dipertahankan.

Cara kerja

  1. Cari kategori dan wilayah di Google Maps.
  2. Buka satu profil bisnis, klik ikon ekstensi, lalu “Baca bisnis yang dibuka”.
  3. Periksa detail, isi wilayah, lalu simpan.
  4. Catat izin WhatsApp beserta sumber dan waktunya.
  5. Preview pesan, buka WhatsApp Web, dan tekan Kirim sendiri.
  6. Catat hasil serta tanggal follow-up. Bila menerima STOP, klik “Jangan hubungi”.

Data tersimpan di profil browser ini, bukan terenkripsi oleh aplikasi. Backup secara berkala dan simpan di tempat pribadi. Menghapus ekstensi/profil dapat menghapus data. Backup JSON berisi data kontak.

Alat ini tidak membaca balasan WhatsApp, tidak memastikan nomor terdaftar, tidak melakukan scraping massal, dan tidak mengakali CAPTCHA. Penggunaan serta penyimpanan data Maps tetap mengikuti ketentuan sumber.
